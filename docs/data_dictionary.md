# Data Dictionary

This document describes the schema for the four relational tables generated by the synthetic data pipeline. All tables are linked through the `employee_id` foreign key.

---

## Table: `employees`

Core demographic and employment information for each employee.

| Column | Type | Description | Range / Valid Values |
|---|---|---|---|
| `employee_id` | `str` | Unique identifier | `EMP-0001` to `EMP-NNNN` |
| `first_name` | `str` | First name (Faker-generated) | Free text |
| `last_name` | `str` | Last name (Faker-generated) | Free text |
| `email` | `str` | Corporate email address | `firstname.lastname.id@company.com` |
| `gender` | `str` | Gender identity | `Male`, `Female`, `Non-Binary` |
| `department` | `str` | Organisational department | `Engineering`, `Sales`, `Marketing`, `HR`, `Finance`, `Operations`, `Product`, `Customer Support` |
| `job_title` | `str` | Role title derived from department and level | Department-specific (see below) |
| `job_level` | `int` | Career level within the department | `1` (entry) to `6` (executive) |
| `hire_date` | `date` | Date the employee was hired | `2010-01-01` to `2023-12-31` |
| `age` | `int` | Employee age at generation time | `22` to `60` |
| `education` | `str` | Highest education level attained | `High School`, `Bachelor`, `Master`, `PhD` |
| `location` | `str` | Primary work location | `New York`, `San Francisco`, `Chicago`, `Austin`, `Seattle`, `Boston`, `Denver`, `Remote` |
| `base_salary` | `float` | Annual base salary in USD | ~$35,000 to ~$220,000 (varies by department, level, and education) |
| `is_active` | `bool` | Whether the employee is currently active | `True` (~85%), `False` (~15%) |

### Department Distribution Weights

| Department | Weight |
|---|---|
| Engineering | 25% |
| Sales | 15% |
| Operations | 12% |
| Marketing | 10% |
| Finance | 10% |
| Product | 10% |
| Customer Support | 10% |
| HR | 8% |

### Education Distribution Weights

| Education Level | Weight | Salary Multiplier | Performance Bonus |
|---|---|---|---|
| High School | 10% | 0.85x | -0.15 |
| Bachelor | 45% | 1.00x | 0.00 |
| Master | 35% | 1.12x | +0.10 |
| PhD | 10% | 1.25x | +0.20 |

## Table: `evaluations`

Semi-annual performance reviews with multi-dimensional ratings. Each active employee receives one evaluation per period after their hire date.

| Column | Type | Description | Range / Valid Values |
|---|---|---|---|
| `evaluation_id` | `str` | Unique evaluation identifier | `EVAL-000001` to `EVAL-NNNNNN` |
| `employee_id` | `str` | Foreign key to `employees` | `EMP-XXXX` |
| `evaluation_period` | `str` | Half-year period label | `H1-2021`, `H2-2021`, ..., `H2-2024` |
| `evaluation_date` | `date` | Actual date the evaluation was conducted | Within the corresponding period |
| `performance_score` | `float` | Overall performance rating | `1.0` to `5.0` |
| `potential_score` | `float` | Growth potential rating | `1.0` to `5.0` |
| `goals_met_pct` | `float` | Percentage of goals achieved | `0.0` to `100.0` |
| `manager_rating` | `float` | Direct manager's rating (slight positive bias) | `1.0` to `5.0` |
| `peer_rating` | `float` | Average peer review rating | `1.0` to `5.0` |
| `self_rating` | `float` | Self-assessment rating (tends higher) | `1.0` to `5.0` |
| `overtime_hours` | `int` | Overtime hours during the period | `0` to `80` |
| `projects_completed` | `int` | Number of projects completed | `0` to `10` |
| `innovation_score` | `float` | Innovation and creativity sub-score | `1.0` to `5.0` |
| `communication_score` | `float` | Communication effectiveness sub-score | `1.0` to `5.0` |
| `leadership_score` | `float` | Leadership capability sub-score | `1.0` to `5.0` |

### Evaluation Periods

| Period | Start Date | Evaluation Window |
|---|---|---|
| H1-2021 | 2021-01-01 | June--July 2021 |
| H2-2021 | 2021-07-01 | December 2021 |
| H1-2022 | 2022-01-01 | June--July 2022 |
| H2-2022 | 2022-07-01 | December 2022 |
| H1-2023 | 2023-01-01 | June--July 2023 |
| H2-2023 | 2023-07-01 | December 2023 |
| H1-2024 | 2024-01-01 | June--July 2024 |
| H2-2024 | 2024-07-01 | December 2024 |

### Score Correlations

- **Performance score** is the composite metric driven by latent ability, tenure, education, department, and temporal autocorrelation (0.55 current + 0.45 previous).
- **Potential score** is derived from 0.45 * performance + 0.35 * latent ability + noise.
- **Manager rating** has a slight positive bias (+0.10) relative to performance.
- **Self rating** has a stronger positive bias (+0.30) relative to performance.
- **Peer rating** is centred on performance with moderate noise.

## Table: `training_records`

Individual training course completions, with 2--6 records per employee per active year.

| Column | Type | Description | Range / Valid Values |
|---|---|---|---|
| `training_id` | `str` | Unique training record identifier | `TR-000001` to `TR-NNNNNN` |
| `employee_id` | `str` | Foreign key to `employees` | `EMP-XXXX` |
| `training_name` | `str` | Course title | See category breakdown below |
| `training_category` | `str` | Broad training category | `Technical`, `Leadership`, `Communication`, `Compliance`, `Domain` |
| `start_date` | `date` | Course start date | Within the employee's active years (2021--2024) |
| `end_date` | `date` | Course end date | `start_date` + duration in days |
| `hours` | `int` | Total training hours | `4` to `40` |
| `status` | `str` | Completion status | `Completed`, `In Progress`, `Dropped` |
| `score` | `float` or `null` | Assessment score (only for completed courses) | `50.0` to `100.0` (null if not completed) |
| `cost` | `float` | Training cost in USD | >= $50.00 (varies by category and hours) |

### Training Categories and Base Costs

| Category | Base Cost (per 20h) | Example Courses |
|---|---|---|
| Technical | $800 | Python for Data Science, Advanced Machine Learning, Cloud Architecture (AWS) |
| Leadership | $1,200 | Leadership Essentials, Managing High-Performing Teams, Strategic Thinking Workshop |
| Communication | $600 | Effective Communication, Presentation Skills, Negotiation Tactics |
| Compliance | $300 | Compliance & Ethics, Diversity & Inclusion, Data Privacy (GDPR/CCPA) |
| Domain | $900 | Financial Modelling, Product Strategy, Design Thinking |

### Status Distribution

Completion rates are correlated with the employee's latent ability:

- **Completed**: ~70--95% (higher ability employees complete more)
- **In Progress**: variable remainder
- **Dropped**: ~2--10% (lower ability employees drop more)

## Table: `promotions`

Career advancement events occurring on quarterly cycles (March, June, September, December).

| Column | Type | Description | Range / Valid Values |
|---|---|---|---|
| `promotion_id` | `str` | Unique promotion identifier | `PROM-0001` to `PROM-NNNN` |
| `employee_id` | `str` | Foreign key to `employees` | `EMP-XXXX` |
| `promotion_date` | `date` | Date the promotion was effective | Quarterly dates within 2021--2024 |
| `previous_level` | `int` | Job level before promotion | `1` to `5` |
| `new_level` | `int` | Job level after promotion | `2` to `6` |
| `previous_title` | `str` | Job title before promotion | Department-specific title for `previous_level` |
| `new_title` | `str` | Job title after promotion | Department-specific title for `new_level` |
| `salary_increase_pct` | `float` | Percentage salary increase | `5.0` to `25.0` |
| `performance_at_promotion` | `float` | Performance score at the time of promotion | `3.5` to `5.0` |

### Promotion Probability

The annual promotion probability depends on average performance:

| Avg Performance | Approx. Annual Probability |
|---|---|
| 1.0 | ~3% |
| 3.0 | ~7% |
| 5.0 | ~11% |

Employees at level 6 (executive) and inactive employees are ineligible for promotion.

---

## Entity-Relationship Summary

```
employees (1) ---< (N) evaluations       [via employee_id]
employees (1) ---< (N) training_records   [via employee_id]
employees (1) ---< (N) promotions         [via employee_id]
```

All three child tables reference `employees.employee_id` as a foreign key. There are no direct relationships between `evaluations`, `training_records`, and `promotions`.
