## 🧭 What this app does

This app helps you review employee performance in one place. It brings together simple charts, a 9-box grid, clustering, causal analysis, and prediction tools. You can use it to look at employee data, spot patterns, and compare groups without setting up a data project from scratch.

It includes:

- 9-box grid views for talent review
- Employee grouping with clustering
- Causal analysis with DoWhy
- Explainable machine learning with SHAP
- Prediction tools for performance trends
- A web app built with FastAPI and Streamlit

## 📈 Main features

### 📋 9-box grid

The 9-box grid helps you place employees based on performance and potential. It gives a simple view of talent strength and future growth.

### 👥 Clustering

Clustering groups similar employees together. This helps you find teams or profiles that share the same traits.

### 🔍 Causal inference

The app uses DoWhy to test what may affect performance. This can help you look at the possible effect of training, manager feedback, or other factors.

### 🧠 Explainable AI

SHAP explainability shows why the model made a prediction. This helps you understand which factors had the most influence.

### 🎯 Prediction

The machine learning model estimates future performance patterns. It can help you plan reviews, training, and talent actions.
